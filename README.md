# Unity Miner

Et Unity-repo som i den tilgjengelige versjonen inneholder prosjektet `Miner`. C#-skriptene implementerer blant annet spillerbevegelse, kamerafølging og dynamitt med detonasjon.

## Innhold

- `Miner/Assets/`: scener, grafikk og spillkode.
- `Miner/Assets/Scripts/`: blant annet `PlayerMovement.cs`, `CamearFollow.cs` og `Dynamite.cs`.
- `Miner/Packages/`: Unity-pakkeoppsett.
- `Miner/ProjectSettings/`: editor- og prosjektinnstillinger.
- Repoet inkluderer også historiske Unity-genererte filer, blant annet fra `Library/`.

## Åpne prosjektet

Installer Git LFS og hent LFS-filene ved kloning. Åpne `Miner/` i Unity Hub. `Miner/ProjectSettings/ProjectVersion.txt` angir **Unity 2020.3.24f1**. Bruk en kopi før eventuell oppgradering.

Repoet er omdøpt fra `unitygames` til `unity-miner`, siden den tilgjengelige koden inneholder dette ene spillprosjektet.
